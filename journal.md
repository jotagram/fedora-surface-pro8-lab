### linux-surface compatibility

The linux-surface project currently provides a Fedora 43 compatible kernel.

Because Fedora 44 is still very new, touchscreen and Surface Pen functionality are not fully supported yet.

More information: https://github.com/linux-surface/linux-surface/issues/2146

#### Status

Using the Fedora 43 compatible linux-surface kernel as a workaround.

### Dash to Dock screen flickering

#### Issue

After updating GNOME extensions, the desktop started flickering.

#### Investigation

The issue appeared after a Dash to Dock update.

#### Resolution

Disabling the extension stopped the screen flickering.

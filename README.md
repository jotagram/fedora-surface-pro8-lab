# Fedora 44 on Surface Pro 8 Lab

This repository documents my transition from Windows to Linux using Fedora 44 on a Microsoft Surface Pro 8.

Reference Repository: https://github.com/linux-surface/linux-surface/wiki/Surface-Pro-8

After many years of working with Windows systems, I decided to build hands-on Linux experience by using Linux as my primary operating system in daily life.

The goal of this project is not only to learn Linux administration, but also to document real-world challenges, troubleshooting steps, and lessons learned during the migration process.

## Why this project?

As an IT Engineer, I wanted to gain practical experience with:

- Linux system administration
- Troubleshooting and problem solving
- Hardware compatibility
- Shell customization
- Automation
- Open-source tools
- Documentation best practices

Instead of learning in a virtual machine, I chose to install Fedora directly on my Surface Pro 8 and use it as part of my daily workflow.

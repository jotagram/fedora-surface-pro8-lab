# Fedora 44 on Surface Pro 8 Lab

This repository documents my journey of running Fedora 44 on a Microsoft Surface Pro 8.

The goal is to learn Linux administration, troubleshooting, hardware compatibility, and automation through hands-on experience.

## Hardware

- Microsoft Surface Pro 8
- Fedora 44 Workstation
